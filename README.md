The protocol contains 16 focused maps, numbered 00–15.

- Map 00 routes actor, current reality, bodily autonomy, and primary problem class before the inner-child subprotocol.
- Maps 10–14 cover reassurance/reality uncertainty, actual harm/accountability, medical/substance/perinatal/dependent safety, grief/major transition, and scoped consent/frame repair/provider transition/third-party help.
- Map 15 separates missing instruction, skill acquisition, insight–action gaps, and external scaffolding from missing inner-parent qualities.

The canonical ontology remains **one inner parent with three qualities**: nurturing, protecting, and guiding.

Mermaid maps are living operational control surfaces, not article outlines. Material protocol changes must update topology, ledgers, state/handoff, benchmark fixtures, and executable-runtime crosswalk together. The article remains a separate frozen explanatory artifact until editing is explicitly authorized.

## Operating rule

Load the canonical files before continuing. Commit substantive batches rather than leaving them only in chat. Strict novelty and practical protocol value remain separate dispositions; empty novelty batches can still produce valuable corrections.

## Epistemic labels

- **SURVIVED** — passed the current novelty/coherence/consequence gates; still a hypothesis unless independently established.
- **PROMISING** — worth developing, but not yet through all gates.
- **REJECTED** — failed novelty or coherence; may remain practically useful under a different ledger.
- **RECOVERED** — reconstructed from surviving context; wording may not be verbatim.
