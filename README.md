# Creative Tail Sampling

Durable workspace for the Creative Tail Sampling method and its findings.

The purpose of this repository is to prevent high-value exploratory reasoning from being lost in chat history and to make the method resumable from a canonical checkpoint.

## Canonical files

- [`PROTOCOL.md`](PROTOCOL.md) — current Creative Tail Sampling protocol.
- [`FINDINGS.md`](FINDINGS.md) — compact index of findings, provisional ideas, and the rejection frontier.
- [`MODEL.md`](MODEL.md) — structural model, variables, feedback loops, falsifiers, and predictions.
- [`STATE.md`](STATE.md) — exact current frontier and resume instructions.
- [`runs/`](runs/) — immutable detailed audits and checkpoints.

## Operating rule

Load canonical files before continuing. Commit substantive batches rather than leaving them only in chat. Strict novelty and practical protocol value remain separate dispositions; empty novelty batches can still produce valuable corrections.

## Epistemic labels

- **SURVIVED** — passed current novelty/coherence/consequence gates; still a hypothesis unless independently established.
- **PROMISING** — worth developing but not yet through all gates.
- **REJECTED** — failed novelty or coherence; may remain practically useful elsewhere.
- **RECOVERED** — reconstructed from surviving context; wording may not be verbatim.
