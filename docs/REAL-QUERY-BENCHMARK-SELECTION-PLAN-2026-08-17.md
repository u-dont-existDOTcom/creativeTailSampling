# Real-query benchmark selection plan — Batch 006 and next frontier

**Date:** 2026-08-17  
**Semantic checkpoint before repair:** `db591713a3feb0a1576943408ae356685c0034ec`  
**Status:** plan executed in the same work package

## Goal

Select the 10–20 real, naturally phrased therapy problems most likely to expose missing protocol topology—not merely produce different prose—and use them to improve the map immediately.

## Selection constraints

A candidate enters the benchmark only when:

1. it is a real public first-person help-seeking post;
2. the original post, not comments or a later update, supplies the benchmark input;
3. usernames and incidental identifying details can be removed without changing the problem;
4. the paraphrase does not add `inner child`, `Protector`, `Nurturer`, `Guide`, `reparenting`, diagnosis, or another preferred solution;
5. the case creates a plausible high-value routing conflict;
6. it adds marginal coverage beyond prior fixtures.

## Coverage matrix

Rank candidates by marginal coverage across these axes:

| Axis | Values sought |
|---|---|
| Request actor | self; supporter; caregiver; minor/dependent; mixed |
| Primary problem class | danger; relational/practical; medical; substance; perinatal; grief; certainty/reality uncertainty; actual harm; internal developmental; portfolio |
| Epistemic state | established; disputed; memory uncertainty; metaphysical; possible psychosis; medical uncertainty |
| Third-party stake | none; partner; child/dependent; victim; absent beneficiary; public/legal |
| Temporal pattern | one-turn event; repeated ritual; relapse; progressive deterioration; anniversary/wave; acute state |
| Failure temptation | over-reassure; collude; dismiss; moral absolution; force disclosure; overpathologize; inwardly individualize; overplan |
| Safety consequence | low; material; urgent; dependent/third-party |
| Operation conflict | consent; authority; capacity; provenance; accountability; handoff; sequencing |

## Search and freezing procedure

1. Freeze the map revision being tested.
2. Define empty cells in the coverage matrix.
3. Search public Reddit posts using ordinary-life language, not therapy-framework labels where avoidable.
4. Prefer cases with competing plausible explanations and consequential wrong routes.
5. Exclude comments-only cases, obvious fiction, meme/creative-writing communities, vendor solicitation, and posts whose wording already supplies the desired therapy answer.
6. Freeze source title, URL, date if available, and a minimally identifying paraphrase **before** tracing it through the map.
7. Route the input without reading comments for the expected answer.
8. Classify each failure as:
   - `PASS`;
   - `MISSING_INFORMATION_ONLY`;
   - `WORDING_OR_DELIVERY_DEFECT`;
   - `OPERATION_PERMISSION_DEFECT`;
   - `TOPOLOGY_OR_AUTHORITY_DEFECT`.
9. Patch topology only for the last two categories.
10. Re-run all prior cases after each material topology change.

### Ranking rule for the next batch

Score each source from 0–2 on:

- new actor/problem-class coverage;
- potential harm from a wrong route;
- ambiguity between at least two plausible explanations;
- need for an authority/consent/provenance rule;
- multi-turn trajectory value;
- absence of solution priming.

Select the highest-scoring 12–16 while preserving domain diversity. Do not choose several near-duplicates merely because they are dramatic.

## Stopping rule

Stop adding map branches when new real cases can be handled through existing topology plus case-specific information. Preserve them as regression fixtures. Add topology only when the bot would otherwise have to invent:

- a missing authority rule;
- a missing permission gate;
- a missing primary problem class;
- a dead end;
- an unsafe fallback;
- an epistemic category;
- or an exit criterion.
