# Operation-permission and required-fields supplement — Batch 007

Date: 2026-08-17  
Status: conceptual runtime contract to reconcile with the existing O0–O10 operation classes; do not create a parallel engine

## Capability / insight–action fields

- `insight_present`: absent / partial / present / unknown
- `cue_detected_when`: before / during / after / not detected / unknown
- `inhibition_available`: yes / no / context-dependent / unknown
- `alternative_response_known`: yes / no / partial / unknown
- `alternative_response_rehearsed`: yes / no / partial / unknown
- `skill_or_instruction_deficit`: present / absent / unknown
- `instruction_access`: adequate / blocked / unavailable / unknown
- `environmental_support`: adequate / inadequate / unknown
- `context_generalization`: present / absent / partial / unknown

Witness capacity must not populate these fields automatically.

## Unknown semantics

As elsewhere, `unknown` restricts only operations requiring the missing fact. It does not authorize invention from tone or globally disable low-demand support.
