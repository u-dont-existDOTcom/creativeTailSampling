# Real-query saturation Batch 009

Date: 2026-08-18  
Base main: `c24fef6f3700fe3795d81edfcc6aba38ff685898`

This is the final planned **architecture-saturation** batch for the inner-child/reparenting therapy protocol.

## Corpus integrity

- Ten real public first-person problem statements.
- Original posts or an original Reddit story reproduced in a public transcript.
- Usernames and incidental identifying details removed.
- Comments, replies, moderator answers, and later updates excluded from expected-route design.
- Target-framework vocabulary and preferred diagnoses/solutions were not added.
- Where a source contained diagnostic or causal priming, that material was removed from the black-box query.
- Source claims remain unverified.
- Only each case file's `query` field belongs in future model input.

## Coverage

- lost time in a minor without DID/OSDD priming;
- culture-sensitive hospice decisions;
- food insecurity with unavailable family/resources;
- parenting guilt after frightening or hurting a child;
- reciprocal violence, intoxication, and toddler safety;
- abortion, grief, bodily autonomy, and public shaming;
- unaffordable clinician-recommended treatment;
- uncertain childhood-abuse memory and current-child-safety questions;
- current abuse and possible alternate placement for a minor;
- guardian denial of a dependent minor's diagnosed medical needs.

## Saturation result

Initial traversal:

- 8/10 cases passed existing maps 00–16 without new topology.
- 2/10 exposed the **same** handoff defect: the correct external resource was identified but genuinely unavailable, unaffordable, waitlisted, unsafe, or otherwise unreachable.

Correction:

- no map 17 was added;
- the canonical overview, map 00, and map 07 now treat `resource unavailable` as a first-class state;
- the fallback records the barrier, reduces immediate harm, finds the smallest reachable substitute, states its limits, preserves the unmet need, and defines a retry/advocacy trigger.

Post-patch traversal:

- 10/10 cases pass conceptually;
- no new authority, permission, epistemic, capacity, or exit branch is required.

## Stopping rule reached

The Mermaid architecture is now considered **conceptually saturated for open-ended real-query expansion**.

Future real cases should be added as regression fixtures, not new branches, unless:

1. the executable InnerSignalGraph implementation exposes a genuinely missing structural rule;
2. qualified clinical/legal/safeguarding review identifies a high-severity omission;
3. a real adverse-event trajectory demonstrates that the existing fallback cannot represent the necessary action.

This is not clinical or deployment-safety validation.
