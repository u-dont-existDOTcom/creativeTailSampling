# Real-query Batch 008

This directory contains eleven real, naturally phrased therapy-problem fixtures used to stress-test the canonical protocol after Batches 006–007.

## Corpus policy

- Public original first-person posts, except RQ8-01, which uses a verbatim original-post quotation published inside a peer-reviewed qualitative Reddit study.
- Usernames and incidental identifying details removed.
- Light paraphrase preserves the original uncertainty and problem structure.
- Comments and later updates did not determine the expected route.
- No `inner child`, `Nurturer`, `Protector`, `Guide`, `reparenting`, preferred diagnosis, or preferred treatment was added to the query text.
- Source claims remain unverified stress-test inputs, not clinical or factual adjudications.
- InnerSignalGraph should send only the `query` field to the therapeutic runtime. Expected routes, defects, and regression assertions remain grader-only.

## Coverage

1. eating-disorder recovery ambivalence and extreme hunger;
2. confession pressure with uncertain memory and possible right-to-know;
3. supporting a suicidal spouse who refuses help;
4. post-stroke/dementia treatment refusal and contested capacity;
5. hoarding, prior guardianship, and caregiver boundaries;
6. leaving a totalizing childhood ministry role and worldview structure;
7. grief plus chronic illness and social pressure to perform recovery;
8. young-adult caregiver burnout and structural load;
9. violent temper, property destruction, and insight without control;
10. medication benefit, adverse effects, self-medication, and severe insomnia;
11. structural economic/healthcare hopelessness.

## Result

- **One new focused map:** map 16, decision capacity, supported choice, and ambivalence.
- **Four targeted cross-map repairs:** eating-disorder/medication routing in map 12; supporter limits in map 14; confession-rights differentiation in maps 10–11; totalizing-role/worldview exit in map 13.
- **Five cases exposed material specification gaps.**
- **Six cases passed without new topology** and remain regression fixtures.

The batch therefore justifies one further iteration but also supports the stopping rule: do not add branches merely because a new topic appears.
