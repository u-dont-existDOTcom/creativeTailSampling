## Material topology change

The inner-child/reparenting protocol is now explicitly a **subprotocol inside a thin actor/problem-class router**.

Before witness, child, Protector, or one-inner-parent routing, the system determines:

1. who the requested help is for;
2. whether immediate danger/basic needs/condition-specific emergency overrides ordinary support;
3. the primary problem class;
4. whether inner work is primary, adjunctive, deferred, or not relevant to the next action.
