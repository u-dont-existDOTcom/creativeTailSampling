## Active unresolved protocol candidates after this audit

These remain research/design questions because they can still change bot behavior:

1. **ICP004-12 / ICP004-14:** what qualitative observations are necessary and sufficient enough for deliberate depth re-entry after destabilization or incomplete integration, without false scoring, symptom-free requirements, or indefinite stabilization?
2. **ICB002-05 / ICP004-02:** does the Nurturer/Protector/Guide intervention-mismatch matrix improve actual routing beyond the simpler `what process is active → what response helps?` formulation?
3. **Parentification-linked overfunctioning:** which current-function markers are useful enough for routing without overpathologizing competence or inferring developmental history that has not been established?
4. **Future machine routing:** which recognition/failure/provenance/permission fields must be mandatory for each transition, and how should an explicit `unknown` state constrain action?
5. **Role-interface complexity:** does the thin N/P/G interface outperform a simpler adult-led formulation in clarity, safe action, autonomy, functioning and burden?
6. **Longitudinal bot safety:** how should multi-turn safety be validated in real use, including privacy/retention, false-positive escalation, gradual-risk misses and actionability of external-support paths?

### Questions closed in this pass

- **Guard re-entry:** do **not** encode a precommitted retry contract. A clear refusal stops/changes optional introspection; later work requires renewed consent. Anti-avoidance reasoning remains relevant to classification, external responsibility and self-endorsed graded approach.
- **Internal constitution:** do **not** build a formal inner legal order. Retain the thin interface contract only if it demonstrably resolves conflict with acceptable complexity: states report; Protector triggers review; Guide proposes; Nurturer cares; optional introspection requires consent; the present adult integrates and owns external action/consequences.
- **Global `stabilize first` gate:** reject. Use the least restrictive sufficient capacity gate for the specific next operation.
- **Parentified competence = fake adulthood:** reject. Competence can be real and adaptive; target costly asymmetry/rigidity, and require developmental evidence before attributing it to parentification.
- **Function-matching novelty:** reject. Mode-sensitive intervention matching has direct Schema Therapy prior art; only the usefulness of this project's N/P/G shorthand remains to test.

Everything else in the retained practical set is already represented in the active Mermaid architecture or explicitly preserved as research history.
