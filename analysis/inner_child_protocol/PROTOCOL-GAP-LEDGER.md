## Dead-end audit

### Dead end repaired: `guard says no → stop`

Old risk: stopping optional introspection could become an absorbing state with no way to revisit the blocked branch.

Current architecture: stop the elicitation **now**, work with what the response protects/needs/predicts, improve real safety/reliability, and reassess. A more formal re-entry contract remains provisional because it could itself become coercive.

### Dead end repaired: `borrowed adult → helper stays adult forever`

Current architecture requires participation/initiation/internalization of the reparenting function while allowing healthy interdependence to continue. Severe stress can route to re-borrowing without resetting developmental status to zero.

### Dead end repaired: `promise missed → trust collapse / bigger vow`

Current architecture explicitly routes miss → acknowledgment → impact → repair → diagnosis → renegotiation → return.

### Dead end repaired: `poor outcome → method failed`

Current architecture localizes failure before escalating the inference to a specific mechanism or broader model.

## Loops requiring exit criteria

1. **regulate → reassess:** exit when enough present orientation/choice/function returns for the next bounded step; do not invent a universal symptom score.
2. **protector dialogue → reassess:** exit when the next safe/meaningful action is clear, not when the protector has been rhetorically persuaded.
3. **identity experimentation → reassess:** exit toward reparenting when enough self/child contact exists to work relationally; identity development can still continue in parallel.
4. **trust test → repeat:** widen only after actual reliable behavior; do not demand a fixed number of repetitions.
5. **failure diagnosis → retry:** retry only after changing the hypothesis/intervention variable that plausibly produced the failure; avoid identical repetition justified only by `more dose`.

## Conflicting-rule audit

### `Listen to no` versus `adult leads`

Current minimum adjudication:

- optional introspective elicitation remains consent-based;
- present feelings/preferences get heard as data;
- the present adult retains responsibility for external actions/consequences;
- immediate safety can require action despite internal dislike;
- Nurturer care remains available during conflict;
- full jurisdiction theory remains provisional.

### `Guide requires difficulty` versus `do not destabilize`

Current adjudication:

- discomfort is not automatically danger;
- loss of orientation, choice, or meaningful function outranks growth/depth goals;
- challenge should be proportionate and purpose-linked, not intensity-seeking.

### `Internalize` versus `keep support`

Resolved conceptually:

- internalize the **reparenting function**;
- continue chosen external relationships/support as needed;
- authority dependency is a separate risk dimension.

### `felt sense may know` versus `do not treat feeling as historical proof`

Resolved conceptually:

- preserve epistemic possibility;
- preserve source provenance;
- do not turn salience into certainty.

## Highest-priority unresolved protocol questions

1. Can the guard/Guide conflict be specified more rigorously without importing coercion or avoidance?
2. Does explicit internal jurisdiction outperform simpler `adult integrates inputs and owns consequences` guidance?
3. Is the no-arrears rule a useful distinct therapeutic instruction, and where must accountability exceptions be explicit?
4. Is external-helper function concentration a distinct dependency risk worth tracking?
5. Does cumulative integration load justify a separate gate before repeated depth amplification?
6. What practical criteria best distinguish parentified pseudo-adulthood from flexible integrated adult capacity without pathologizing competence?
7. Which recognition/failure fields are essential enough that a future bot must collect them before routing rather than infer them?
